# Screenshots Folder

This folder is for app screenshots used in the PWA manifest and documentation.

## Adding Screenshots

Once your app is running, take screenshots to showcase it:

1. **Main Screen**: Showing the pollen and air quality data
2. **Recommendations**: Showing the personalized recommendations
3. **Favorites**: Showing the favorites modal
4. **Hourly Forecast**: Showing the hourly data

## Screenshot Specifications

For PWA manifest:
- **Size**: 540x720 pixels (portrait)
- **Format**: PNG
- **Naming**: `home.png`, `recommendations.png`, etc.

## Optional

You can remove the screenshots section from `manifest.json` if you don't want to provide screenshots.
